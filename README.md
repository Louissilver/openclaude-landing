# OpenClaude Landing Page

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](https://github.com/Louissilver/openclaude-landing/pulls)

Landing page estática para o **OpenClaude** — um agente de código open-source que roda no seu terminal e acelera seu fluxo de trabalho com inteligência artificial.

> **Desenvolvido 100% com OpenClaude**, integrado ao provedor **OpenRouter**, utilizando dois modelos gratuitos:
> - `poolside/laguna-s-2.1:free`
> - `nvidia/nemotron-3-ultra-550b-a55b:free`

## Instalação

```bash
# Clone este repositório
git clone https://github.com/Louissilver/openclaude-landing.git

# Acesse a pasta
cd openclaude-landing
```

---

## Uso

```bash
# Inicie o servidor local
npx serve -l 3000
```

Acesse `http://localhost:3000` no seu navegador.
