# OpenClaude Landing Page

Landing page estática para o OpenClaude — um agente de código open-source que roda no seu terminal.

> **Desenvolvido 100% com OpenClaude**, integrado ao provedor **OpenRouter**, utilizando dois modelos gratuitos:
> - `poolside/laguna-s-2.1:free`
> - `nvidia/nemotron-3-ultra-550b-a55b:free`

## Tecnologias

- HTML5
- CSS3 (tema escuro)
- JavaScript (interatividade e animações)

## Publicação

- **GitHub Pages** — https://louissilver.github.io/openclaude-landing/

## Desenvolvimento local

```bash
npx serve -l 3000
```
