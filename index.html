Instalação rápida e configuração simples

terminal 
# Instalação rápida
npm install -g @openclaude/cli

# Ou via script de instalação
curl -fsSL https://openclaude.dev/install.sh | sh

# Inicie no seu projeto
cd meu-projeto
openclaude

# Escolha seu provedor e modelo
# Comece a codificar!

Configuração com OpenRouter

Aprenda a escolher um modelo, gerar uma API Key e configurar no OpenClaude

01

Criar Conta e API Key

  1. Acesse https://openrouter.ai
  2. Clique em "Sign In" e crie uma conta gratuita
  3. No dashboard, vá em "API Keys"
  4. Clique em "Create New Key", dê um nome e confirme
  5. Copie a chave gerada (ela começa com sk-or-v1-...)

03

Configurar no OpenClaude

Configure usando comandos interativos ou variáveis de ambiente:

terminal 
# Execute no terminal
openclaude --provider openrouter

# O CLI pedirá a chave da API
# Digite sua key: sk-or-v1-...

# Selecione o modelo
# → anthropic/claude-3-opus

# Salvo em ~/.config/openclaude/config.json
# Pronto! Agora é só usar:
openclaude
terminal 
# No seu .bashrc, .zshrc ou .env
export OPENROUTER_API_KEY="sk-or-v1-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

# Especificar o modelo por padrão
export OPENROUTER_MODEL="anthropic/claude-3-opus"

# Inicie o OpenClaude normalmente
openclaude

Dicas Rápidas

  • Modelo gratuito: Use :free no final do modelo para acesso à camada gratuita do OpenRouter
  • Rate limit: Modelos gratuitos têm quota diária — monitore no dashboard OpenRouter
  • Mudar modelo: Execute /model nome/do/modelo dentro do OpenClaude a qualquer momento
  • Debug: Use /debug para ver tokens usados e latência
